# Permission Test Cases

## Admin

- [ ] Can access dashboard
- [ ] Can manage products
- [ ] Can manage inventory
- [ ] Can manage sales
- [ ] Can void sales
- [ ] Can manage users
- [ ] Can manage roles and permissions
- [ ] Can access backup and restore

## Manager

- [ ] Can access dashboard
- [ ] Can manage products if permission is enabled
- [ ] Can view reports
- [ ] Cannot change admin-only settings unless permission is enabled

## Cashier

- [ ] Can access POS checkout
- [ ] Can complete sales
- [ ] Cannot access user management
- [ ] Cannot access backup and restore
- [ ] Cannot void sales unless permission is enabled
